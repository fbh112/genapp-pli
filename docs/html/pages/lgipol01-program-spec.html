LGIPOL01 Module Reference

LGIPOL01 is a CICS-hosted PL/I program that serves as the business logic front-end for an insurance policy inquiry transaction. It receives a communication area (COMMAREA) containing a customer number and policy number, initialises a success return code, then delegates the actual database retrieval to a backend program (LGIPDB01) via a CICS LINK call. After data is returned, it applies a business rule override — extending the policy expiry date to 2099-01-01 for any motor policy where the vehicle make is HONDA — before returning control to the caller. The program also includes error-handling logic that abends the transaction if no COMMAREA is present, and a diagnostic subroutine that writes timestamped error messages to a transient data queue via the LGSTSQ utility program.

1. Overview

LGIPOL01 acts as an intermediate coordination layer in an insurance policy inquiry transaction flow. It supports all major policy types — Endowment, House, Motor, and Commercial — and is responsible for:

  • Validating that a COMMAREA was supplied by the calling transaction
  • Initialising the return code to a default success state
  • Forwarding the request to the backend database access program LGIPDB01
  • Applying post-retrieval business rules (Honda vehicle expiry date override)
  • Returning the populated COMMAREA to the caller
  • Logging structured diagnostic messages and raw COMMAREA snapshots on error via LGSTSQ

The program is built around two core procedures: the main entry body (LGIPOL01) which drives the inquiry lifecycle, and the WRITE_ERROR_MESSAGE subroutine which handles all diagnostic logging activity.

LGIPOL01 is the sole point of contact for the calling transaction. It never reads from DB2 directly — all data persistence concerns are delegated to LGIPDB01. Similarly, all diagnostic output is routed through the shared LGSTSQ utility, keeping logging concerns cleanly separated.

3. COMMAREA Interface

3.1 Input Fields

All business inputs are carried within the COMMAREA structure and are made available through the %INCLUDE LGCMAREA copybook. The COMMAREA is passed via the COMM_AREA_PTR pointer parameter at program entry.

Field Type / Size Direction Description
CA_RETURN_CODE 2-digit numeric In/Out Outcome of the inquiry. Initialised to '00' (success) at start; overwritten by LGIPDB01.
CA_CUSTOMER_NUM 10-digit numeric Input Customer identifier for the policy inquiry. Copied into error message structure for tracing.
CA_POLICY_NUM 10-digit numeric Input Unique policy identifier. Copied into error message structure and forwarded to LGIPDB01.
