Policy Add Program (LGAPOL01)

LGAPOL01 is the core business logic program responsible for adding new insurance policies (endowment, house, motor, commercial, or claim) within the GenApp CICS/PL/I application suite. It validates the communication area (COMMAREA), optionally coordinates with IBM Operational Decision Manager (ODM) via LGAPBR01 for business rule evaluation on endowment policies, and delegates database persistence to the DB2 data-access module LGAPDB01.

1. Overview

LGAPOL01 operates as the middle-tier coordinator in a three-tier architecture. It processes policy addition requests by performing structural validation, delegating business rules when configured, coordinating database operations, and handling diagnostic logging in case of system anomalies.

1.1 Core Responsibilities

  • Interface Verification: Ensures incoming requests have a valid CICS COMMAREA structure and meet minimum byte length requirements.
  • Business Rule Delegation: Conditionally routes endowment policy additions to the ODM rules processor (LGAPBR01) when business rules processing is enabled.
  • Data Layer Delegation: Passes the policy payload to the DB2 access program (LGAPDB01) for database insertion into base and subtype tables.
  • Diagnostic Logging: Formats and dispatches runtime error diagnostics to Transient Data Queues (TDQ) or Temporary Storage Queues (TSQ) using utility program LGSTSQ upon failure.

3. Inputs and Execution Context

3.1 Communication Area (COMMAREA) Structure

The program expects a single pointer parameter COMM_AREA_PTR addressing a 32,500-byte structure defined by include file LGCMAREA.inc.

  • CA_REQUEST_ID (CHAR(6)): Transaction and policy operation identifier (e.g., '01AEND' for Add Endowment, '01AMOT' for Add Motor, '01AHSE' for Add House, '01ACON' for Add Commercial).
  • CA_RETURN_CODE (PIC '99'): Two-digit return code initialized to '00'.
  • CA_CUSTOMER_NUM (PIC '9999999999'): 10-digit customer identifier.
  • CA_POLICY_NUM (PIC '9999999999'): 10-digit target policy identifier.

3.3 CICS Runtime Environment & Configuration Flags

  • EIBCALEN: Length of passed COMMAREA. Used to verify payload presence.
  • EIBTRNID, EIBTRMID, EIBTASKN: CICS Transaction ID, Terminal ID, and Task Number captured at startup for operational diagnostics.
  • BUSINESS_RULES (CHAR): Internal toggle initialized to 'N'. When set to 'Y' at compilation/source level, enables invocation of LGAPBR01 for endowment add requests (01AEND).

4. Outputs and Interfaces

4.1 Communication Area Output Data

Upon execution completion, COMM_AREA is returned to the invoking CICS program with updated values:

  • CA_RETURN_CODE: Status indicator:
    • '00': Policy successfully added.
    • '98': COMMAREA length validation error (EIBCALEN less than required minimum header size).
    • > 0: Error code propagated from LGAPDB01 or LGAPBR01.
  • CA_POLICY_NUM: Contains the newly generated 10-digit policy identifier produced by LGAPDB01.

4.2 External Program Interfaces

  • EXEC CICS LINK PROGRAM('LGAPBR01'): Invoked conditionally when BUSINESS_RULES = 'Y' and CA_REQUEST_ID = '01AEND'. Passes the 32,500-byte COMMAREA to validate endowment business rules.
  • EXEC CICS LINK PROGRAM('LGAPDB01'): Invoked to execute the database INSERT operation for the base POLICY and corresponding subtype tables.
  • EXEC CICS LINK PROGRAM('LGSTSQ'): Invoked inside WRITE_ERROR_MESSAGE to log formatted diagnostic messages (ERROR_MSG) and raw COMMAREA dumps (CA_ERROR_MSG) to the operational CICS TDQ.

4.3 Abnormal Termination and Return Mechanism

  • EXEC CICS ABEND ABCODE('LGCA') NODUMP: Executed immediately if EIBCALEN = 0.
  • EXEC CICS RETURN: Exits program execution and returns the updated COMM_AREA back to the caller.

5.2 Detailed Step-by-Step Processing Logic

  1. Context Initialization: On entry via EXEC CICS LINK, the program copies EIBTRNID, EIBTRMID, EIBTASKN, and EIBCALEN into working-storage tracking variables.
  2. Missing COMMAREA Check: If EIBCALEN is equal to 0, WRITE_ERROR_MESSAGE is invoked to write diagnostic metadata (NO COMMAREA RECEIVED) to the queue, and an immediate EXEC CICS ABEND ABCODE('LGCA') NODUMP is issued.
  3. Return Code & Header Setup: CA_RETURN_CODE is initialized to '00'. CA_CUSTOMER_NUM is copied into the error message structure for tracking.
  4. Length Boundary Check: WS_REQUIRED_CA_LEN (28 bytes minimum header) is evaluated against EIBCALEN. If EIBCALEN is insufficient, CA_RETURN_CODE is set to '98' and control returns immediately.
  5. ODM Business Rules Validation: If BUSINESS_RULES equals 'Y' and CA_REQUEST_ID equals '01AEND', LGAPBR01 is linked. For all other request IDs (01AHSE, 01AMOT, 01ACON) or if BUSINESS_RULES = 'N', this invocation is skipped.
  6. DB2 Persistence Execution: LGAPDB01 is linked to perform the DB2 insert. LGAPDB01 populates CA_POLICY_NUM and updates CA_RETURN_CODE.
  7. Return Code Evaluation: If CA_RETURN_CODE > '00', the program immediately exits. Otherwise, normal EXEC CICS RETURN transfers control and data back to the caller.

5.3 Program Paragraphs Breakdown

  • Main Initialization: Reads CICS system values from the Execute Interface Block (EIB) into working storage.
  • Commarea Validation: Validates existence and length of COMM_AREA. Handles abends (LGCA) or early exit codes (98).
  • Business Rule Processing: Evaluates the BUSINESS_RULES flag and request ID to conditionally call LGAPBR01.
  • Data Insertion: Dispatches the request to LGAPDB01 and monitors the return code.
  • WRITE_ERROR_MESSAGE: Subroutine that queries timestamps (ASKTIME, FORMATTIME), formats error structures, extracts up to 90 bytes of raw COMMAREA data, and calls LGSTSQ.

6.2 Target Table Descriptions

  • POLICY: Master policy table containing common attributes across all insurance products.
  • ENDOWMENT_POLICY: Specialized table storing life assured details, investment fund selections, and sum assured.
  • HOUSE_POLICY: Specialized table storing residential structure specifications and property valuation.
  • MOTOR_POLICY: Specialized table storing vehicle registration, engine specs, and accident history.
  • COMMERCIAL_POLICY: Specialized table storing commercial enterprise peril ratings (fire, flood, crime, weather) and location coordinates.

7. Dependencies and Technical Constraints

7.1 Program Dependencies

  • LGAPDB01: DB2 data tier module linked unconditionally to insert records.
  • LGAPBR01: Rules module linked conditionally for endowment additions when enabled.
  • LGSTSQ: Diagnostic logging utility program linked to write error structures to CICS queues.
  • LGCMAREA.inc: Core include file defining the 32,500-byte communication area structure.

7.2 Structural and Runtime Constraints

  • Zero-Payload Guard: Execution without a passed COMMAREA (EIBCALEN = 0) triggers an immediate ABEND LGCA NODUMP.
  • Length Constraint: COMMAREA must be at least 28 bytes (WS_CA_HEADER_LEN). If shorter, the program exits with CA_RETURN_CODE = '98'.
  • Buffer Size Ceiling: The maximum COMMAREA size supported across all linked calls is 32,500 bytes.
  • Business Rule Activation: Business rule integration via LGAPBR01 is disabled by default (BUSINESS_RULES = 'N') and applies strictly to CA_REQUEST_ID = '01AEND'.

7.3 Data Field Format and Sizing Constraints

  • CA_CUSTOMER_NUM / CA_POLICY_NUM / CA_BROKERID: PIC '9999999999' (10 digits).
  • CA_RETURN_CODE: PIC '99' (2 digits).
  • CA_PAYMENT / CA_M_PREMIUM / CA_E_SUM_ASSURED: PIC '999999' (6 digits).
  • CA_H_VALUE / CA_C_VALUE: PIC '99999999' (8 digits).
  • CA_ISSUE_DATE / CA_EXPIRY_DATE: CHAR(10) (YYYY-MM-DD).
  • WS_VARY_CHAR: Endowment padding data capped at 3,900 characters for DB2 VARCHAR insertion.

8. Error Handling and Diagnostic Logging

8.1 Input Validation and Interface Integrity Checks

  • Communication Area Existence Verification: Validates that EIBCALEN > 0. If no area is received, it triggers diagnostic logging and terminates the transaction.
  • Communication Area Minimum Length Validation: Confirms EIBCALEN >= WS_REQUIRED_CA_LEN. If undersized, it sets CA_RETURN_CODE = '98' and performs an early exit.

8.2 Downstream Return Code Evaluation

  • Execution Status Check: Following the CICS link to LGAPDB01, LGAPOL01 evaluates CA_RETURN_CODE. If a non-zero code is detected, it halts further logic and returns the failure code to the caller.

8.3 Abnormal Program Termination (ABEND)

  • Transaction Abend: On zero-length COMMAREA invocations, the program issues EXEC CICS ABEND ABCODE('LGCA') NODUMP, preventing system dumps while recording the failure.

8.4 Diagnostic Logging via LGSTSQ

  • Error Assembly & Timestamping: Uses EXEC CICS ASKTIME and EXEC CICS FORMATTIME to capture the timestamp, then formats an ERROR_MSG structure containing program name (LGAPOL01), customer ID, policy ID, and error description.
  • Contextual Payload Capture: Extracts up to the first 90 bytes of raw COMMAREA (LEFT(COMM_AREA_RAW, 90)) into CA_ERROR_MSG.
  • Queue Dispatch: Invokes LGSTSQ via EXEC CICS LINK to persist diagnostic records to the CICS log queue.

  CA_EXPIRY_DATE     = '2024-10-01'
  CA_BROKERID        = '0000000010'
  CA_BROKERSREF      = 'BRKREF1010'
  CA_PAYMENT         = '000450'
  CA_M_MAKE          = 'Ford'
  CA_M_MODEL         = 'Focus'
  CA_M_VALUE         = '015000'
  CA_M_REGNUMBER     = 'AB12CDE'
  CA_M_COLOUR        = 'Blue'
  CA_M_CC            = '1600'
  CA_M_MANUFACTURED  = '2020-05-15'

9.1.2 Expected Output Data

TEXT 
CICS Commarea (Returned to Caller)
  CA_REQUEST_ID      = '01AMOT'
  CA_CUSTOMER_NUM    = '0000000101'
  CA_POLICY_NUM      = '0000001054'
  CA_RETURN_CODE     = '00'

9.1.3 Processing Summary

  1. LGAPOL01 verifies EIBCALEN >= 28 and initializes CA_RETURN_CODE = '00'.
  2. Because CA_REQUEST_ID is '01AMOT', business rules processing (LGAPBR01) is bypassed.
  3. LGAPDB01 is linked to insert records into POLICY and MOTOR_POLICY tables.
  4. LGAPDB01 assigns policy ID 0000001054, sets CA_RETURN_CODE = '00', and returns control.

9.2 Example 2: Short COMMAREA Length Validation Failure

9.2.1 Sample Input Data

TEXT 
EIBCALEN             = 15
CICS Commarea (Length: 15 bytes)
  CA_REQUEST_ID      = '01AEND'
  CA_RETURN_CODE     = '00'
  CA_CUSTOMER_NUM    = '0000000101'

9.2.2 Expected Output Data

TEXT 
CICS Commarea
  CA_RETURN_CODE     = '98'

9.2.3 Processing Summary

  1. LGAPOL01 evaluates EIBCALEN (15 bytes) against WS_REQUIRED_CA_LEN (28 bytes).
  2. The check fails (15 < 28).
  3. LGAPOL01 assigns CA_RETURN_CODE = '98' and immediately issues EXEC CICS RETURN, bypassing all ODM rules and DB2 database operations.
