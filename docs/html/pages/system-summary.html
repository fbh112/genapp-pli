Executive Summary & Application Landscape

1. Overview

The General Insurance Application (GenApp) is a modular, multi-tier mainframe enterprise application built in PL/I, running on IBM z/OS CICS Transaction Server. It provides end-to-end insurance policy lifecycle management — covering policy inquiry, creation, update, and deletion — across multiple insurance product types including Endowment, House, Motor, and Commercial policies, with associated Claims handling.

GenApp persists data across two complementary storage tiers: an IBM Db2 for z/OS relational database for structured transactional data, and VSAM KSDS datasets for high-speed primary-key-based access. The application exposes its services to multiple entry points — 3270 terminal sessions, CICS Web Services / REST interfaces, and batch callers — all through a unified COMMAREA-based inter-program contract.

The system is organized into four well-defined layers:

  • Presentation / Orchestration — BMS 3270 terminal driver (LGTESTP1)
  • Business Logic — Policy orchestration programs (LGxPOL01) and business rule engine (LGAPBR01)
  • Data Access — Db2 access programs (LGxPDB01) and VSAM access programs (LGxPVS01)
  • Cross-Cutting Services — Centralized error/audit logging (LGSTSQ) and shared COMMAREA contracts (LGCMAREA.inc)

2. System Architecture

The GenApp system is structured as a classic three-tier mainframe architecture hosted entirely within the CICS Transaction Server environment. All inter-program communication uses EXEC CICS LINK with a shared COMMAREA structure, ensuring a consistent and decoupled call model across all layers.
